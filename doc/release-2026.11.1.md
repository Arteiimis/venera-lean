# Venera Lean 2026.11.1

修复 Windows 快速滚动长列表时的闪退，并继续压低本地页与搜索的卡顿。

## 本次更新

- **Windows 不再闪退**（入口：本地页或任意长列表快速滚动）：Flutter 3.50 的 ANGLE 改版会让帧提交与纹理上传共用同一个 D3D11 上下文，驱动层直接崩溃且没有 Dart 日志。本版本在 Windows runner 内为 ANGLE 设备开启 D3D11 多线程保护；同一构建连续甩动本地页 120 次无崩溃、无 dump。升级到包含上游修复的 Flutter 后会自动退化为重复设置，不影响行为。
- **本地页更快**（入口：首页 → 本地）：卡片右下角常驻「来源 · 占用」，占用值缓存进数据库并在工作 isolate 上测量，打开页面不再遍历漫画目录；封面按卡片尺寸解码，首屏 36 张从 118.0 MiB 降到 36.6 MiB，不再撑爆 100 MiB 的图片缓存，二次进入不需要重新解码；收藏/历史徽标不再逐卡片查库，卡片上被裁剪的标签也不再全部参与排版。
- **搜索更跟手**（入口：本地页搜索框、收藏夹搜索、历史页搜索）：三个列表都改为一次读库 + 内存索引/预计算文本，逐键过滤不再触发 SQL 扫描；收藏夹搜索在中文简繁、大小写与连字符上保持一致，网络源收藏夹支持源侧搜索与下一页。
- **列表更快**（入口：首页历史条、历史页）：`history.db` 增加时间索引，首页历史条与历史页的首屏、刷新都更快；「阅读完成」筛选改为一次快照查询。
- **卡片样式**（入口：任意漫画网格）：详细模式下描述区右下角的角标固定贴在封面描述角，简要模式与详细模式共用同一套封面标签。
- **基础升级**：Flutter 3.41.4 → 3.50.1（设计库迁移到 `material_ui`），quickjs-ng 0.18.0，archive 4.7.1；Android 构建工具链升级到 Gradle 9 / AGP 9.3（构建需要 JDK 21，产物与安装方式不变）。

## 升级与迁移

- Android：包名与签名不变，覆盖安装即可；已登录的漫画源、收藏、历史、稍后读与设置保留。
- Windows：便携 ZIP 与安装包都可直接替换旧版本，数据目录仍是 `%APPDATA%\Arteiimis\Venera Lean`；首次启动会在 `history.db` 上建一次时间索引（一次性）。
- 备份格式未变（`format: 2` / `product: venera-lean`），无需重新导出。
